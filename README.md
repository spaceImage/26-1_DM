# 성북구 아파트 실거래가 예측 및 분석 프로젝트

## 프로젝트 개요
* **프로젝트 목적:** 서울시 성북구 아파트의 2021~2025년 실거래가 데이터를 바탕으로, 주변 편의시설(공원, 병원, 상권 등) 및 거시경제 지표(기준금리)가 집값에 미치는 영향을 분석하고 예측 모델을 구축합니다.

## 폴더 구조 및 파일 설명

### 'data'
* **`raw`**: 외부에서 수집한 가공 전 원본 데이터 
  * 국토교통부 아파트 실거래가, 서울시 공공데이터(버스, 지하철, 병원, 공원, 소상공인), 한국은행 기준금리 등
* **`intermediate`**: 결측치 처리 및 공간 데이터(위경도) 결합 등 중간 전처리 과정에서 생성된 데이터
* **`final`**: 모델링과 EDA에 바로 사용할 수 있도록 정제된 최종 병합 데이터

### 2. `notebooks`
* **`main_data.ipynb`**: 원본 데이터 전처리 및 외부 API를 활용한 위경도/거리 계산, 데이터 병합 파이프라인
* **`EDA.ipynb`**: 전처리된 데이터를 바탕으로 한 시각화 및 주요 변수 간 상관관계 분석 (히트맵 등)
* **`modeling.ipynb`**: Machine Learning 알고리즘을 활용한 아파트 가격 예측 모델 구축 및 성능 평가

## 파이프라인 흐름도
1. **Data Preprocessing**: 거래 데이터에 공간 데이터(반경 500m 내 인프라 수) 및 거시경제 변수 결합
2. **EDA**: 아파트 가격과 주요 변수(금리, 층수, 브랜드, 인프라 등)의 상관성 파악
3. **Modeling**: 선형회귀, 랜덤 포레스트, 그래디언트 부스팅, 히스토그램 기반 그래디언트 부스팅 등을 활용한 예측 모델 학습 및 결과 도출

## 사용 기술 스택
* **Language:** Python 3.10.3
* **Library:** Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn
* **API:** Kakao Local API (위경도 변환)
